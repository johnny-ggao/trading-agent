# 分析拆分：确定性候选，LLM 判断

智能体以机械方式计算客观、可测试的部分——swing 枢轴点、支撑/阻力候选区域、斐波那契水平、移动平均线排列——并将它们与指标序列一起交给 LLM。LLM 只负责过滤、命名结构与形态，并写出带有失效位和置信度的方向性结论。

我们拒绝了让 LLM 从原始 OHLCV 推断一切（不可复现且不可验证），也拒绝了纯基于规则的分析器（那不是这个智能体存在所要完成的主观工作）。

## 后果 (Consequences)

- 机械层可以针对参考数据进行单元测试；模型的判断是否可信，只取决于喂给它的候选质量。
- 每个结论都必须带有失效位和高/中/低置信度，使主观判断可被证伪。
- 判断只在已收盘 K 线上运行；未收盘/形成中 K 线可以显示，但绝不触发结构或形态判断。
