# 分析接口：代码负责算，agent 负责选

工单 05 落地时，`trading_chart` 一次返回 `MarketView` 的**全部内容**：固定指标集（MA20/50/200 + 成交量 + MACD）、机械候选（枢轴/支撑阻力/斐波那契）、规则信号、市场状态、多周期共振。指标集由 `DEFAULT_INDICATORS` 预设，模型没有机会决定"这次该看什么"，只能在一个已经装满的盘子里挑。

这限制了推理：判读的**起点**被宿主替模型定了。但把它纠正成"让模型自己算"会重演 [ADR-0002](0002-analysis-split-mechanical-candidates-llm-judgement.md) 拒绝的那条——LLM 对原始 OHLCV 做指标算术既不可复现也不可验证。

两个被耦合的决定必须分开：**指标怎么算**（公式、预热期、只用已收盘 K 线）只能由代码做；**这次算什么**（选哪些、什么参数、多长窗口）应该由 agent 决定。

因此本 ADR 决定：**打开"选什么"的接口，保住"怎么算"的实现。**

- **选择权交给 agent**：新增按需取数的工具族（`trading_indicator` / `trading_levels` / `trading_derivatives`，形态见工单 12）。模型按自己的分析路径逐次请求：先看结构，觉得需要再看波动率、价位敏感度或衍生品，可以改参数、改窗口、改聚类容差。
- **计算权留在代码**：所有数值仍由既有纯函数算出（`indicators.ts` / `candidates.ts` / `signals.ts` / `context.ts`），仍然只用**已收盘** K 线。工具只返回**被点名的那些**，不夹带。
- **`trading_chart` 退化为"出图 + 最小锚点"**：返回 `chartSpec` 与极小机械摘要（现价、已收盘根数、最后一根已收盘 bar 的时间、市场状态的机械事实——趋势/波动/量能）。trading 的机械候选、规则信号、指标序列不再随出图一并灌给模型。
- **每次响应自带 grounding**：用了哪些 K 线、最后一根已收盘 bar 的时间、是否仍有形成中的 bar、指标参数与预热期。数据不足以支撑所请求的指标时**明确返回"数据不足"**，绝不静默给出基于不足窗口的数值。
- **`MarketView` 从契约降级为实现**：它不再是对模型的接口，而是进程内的缓存条目（`trading_confidence` 复用它的方式不变）。模型可见的契约变成"一族小请求/小响应"。

## 后果 (Consequences)

- **渲染固定，推理自由**：主图仍需要"画什么"的预设（均线 + 支撑阻力），所以 `trading_chart` 的参数保留；但这只影响渲染，不再决定模型能推理什么。这条分界必须写在文档里，否则会被反复混淆。
  - **澄清（2026-09-22）**：这里的"固定"指的是**必须有默认值**（不能什么都不画），**不是**图面内容不可配。渲染参数（已有 `ma`/`rsi`/`bollinger`/`kdj`/`atr`，新增 `levelsPerSide`/`levelKinds`）都是**默认值而非牢笼**，模型可以覆盖；图面与分析用同一个取舍策略（`nearestPerSide`），只是默认值不同（图 3/侧求清爽、分析 5/侧求充分）。
  - 指标**不默认画在图上**：它们经图卡工具栏的开关按需打开；代理要"看"数值时走 `trading_indicator`，不必把它们全画上去。
- **回合数与成本上升**：一次典型分析从 1 次工具调用变成 2–4 次（出图 → 指标 → 可选价位/衍生品 → 置信度），每次都是完整模型回合。
- **漏检风险由提示词承接**：预捆绑等于"机械层的强制体检"；改成按需后，模型不问就看不到。spec 里"结构/价位优先、经典形态次之"的优先级从**代码强制**变为**提示词纪律**（skill v3）。最小锚点（市场状态由宿主免费给）是这一风险的缓解措施。
- **一致性 vs 深挖**：不同提问产出的分析路径可能不同，可复现性略降；换来的是能沿用户的真实问题深挖。ADR-0002 的"机械计算可单测"不受影响——纯函数与它们的测试原样保留。
- **工单 08 的落点确定**：Hyperliquid 的补充数据（资金费/OI/标记价/预言机价/溢价/跨场所预测资金费/OI 上限）作为 `trading_derivatives` 的一个来源接入，而不是塞进 `trading_chart` 的返回体。
- **工具数量**：从 2 个（出图、置信度）增至 4–5 个。工具描述必须写清"何时该调我"，否则模型会少调或多调。

## 状态 (Status)

accepted；补充 ADR-0002（`trading_chart` 的固定捆绑改为 agent 按需取数），工单 12 实现。
