# Triage 标签 (Triage Labels)

各个 skill 使用五个规范 triage 角色进行表述。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义                              |
| -------------------------- | -------------------- | --------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue            |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息            |
| `ready-for-agent`          | `ready-for-agent`    | 已完整规格化，可供 AFK 智能体使用 |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现                      |
| `wontfix`                  | `wontfix`            | 不会被处理                        |

当某个 skill 提到某个角色（例如“应用 AFK-ready triage 标签”）时，使用本表中对应的标签字符串。

编辑右侧那一列，以匹配你实际使用的词汇。
