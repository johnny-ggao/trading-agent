# trading_chart 使用指南

## 何时调用

用户问某个**加密**资产的行情或技术面时调用 `trading_chart`：

- 走势、结构、支撑阻力、能不能买、现在什么位置；
- K 线、均线、MACD/RSI/布林带/KDJ/ATR 等指标；
- 要求"画一张图 / 看一眼行情"。

非加密市场（美股、A 股、外汇、期货）、下单与仓位、回测、纯指标概念问答都不调用本工具。

## 参数

只填能从用户话里解析出来的字段，其余留空，由默认值补齐。

| 参数 | 含义 | 填法 |
|---|---|---|
| `symbol` | 币种或交易对 | `"BTC"`、`"ETH"`、`"BTCUSDT"`；裸币种会自动补 USDT |
| `timeframe` | 周期或时间词 | `"15m"`/`"1h"`/`"4h"`/`"1d"`，或下表时间词 |
| `ma` | 均线周期数组 | `[50, 200]`，覆盖默认的 `[20, 50, 200]` |
| `rsi` | RSI 周期 | `14`；传值才显示 RSI |
| `bollinger` | 叠加布林带 | `true` |
| `kdj` | KDJ 副图 | `true` |
| `atr` | ATR 副图 | `true` |

## 时间词 → 主周期

- 今天 → 1h
- 这周 → 4h
- 这月 → 1d
- 短线 → 15m

用户话里写出的具体周期优先于时间词；都解析不出来时用默认周期。

## 默认值

- symbol：BTC
- 周期：默认 1h
- 指标：主图 MA20/50/200，副图 成交量 与 MACD；RSI 默认关闭，布林带/KDJ/ATR 默认关闭。

## 多轮对话

同一对话里沿用上一轮的 symbol 与指标设置。用户只改周期或指标时，只传变化的字段。

## 回答要求

在回答开头用一句话声明本次使用的 symbol、周期与指标（例如"BTC / 1h / MA20/50/200 + 成交量 + MACD"），猜错时用户能立刻纠正。图表由工具自动打开在**右侧栏的「行情图」tab**里（不在对话正文中）。

方向性结论必须带**方向 + 失效位 + 置信度**。置信度优先用 `trading_confidence` 的校准结果（0..1 与 高/中/低），拿不到时用你自己的判断并**声明未经校准**；不要编造校准分数。分析结论由你根据工具返回的指标数值撰写。

## 机械数据怎么用

工具结果里的机械数据（candidates / ruleSignals / context / resonance）是**确定性计算，不是结论**：

- `context` 是市场状态（趋势强度与方向、波动率、量能、均线排列），用作判断的框架；
- `resonance` 是多周期共振：高一级周期定结构与方向、当前周期定时机；
- 你的工作是筛选候选、命名结构与形态，并给出方向 + 失效位 + 置信度。

## 置信度校准（trading_confidence）

形成方向性结论后，调用 `trading_confidence` 让 TypeSafe Jev 校准它的置信度：

| 参数 | 含义 |
|---|---|
| `symbol` | 与 `trading_chart` 一致 |
| `interval` | 与本次出图一致（15m/1h/4h/1d） |
| `direction` | `bullish` / `bearish` / `range` / `unclear` |
| `invalidation` | 失效位（价位或条件，如「跌破 63000」） |
| `thesis` | 你的结论与理由，简短即可（这段文本会发给 Jev 评分） |

- **必须先对同一 symbol/interval 调用过 `trading_chart`**；否则返回 `ok=false, reason=evidence_unavailable`，先出图再校准。
- `ok=true`：回答里同时给出返回的**支持度**（0..4 与档位）、**置信度**（0..1 与 高/中/低），必要时证据充分度；不要改写这些数字。
- `ok=false`（未配置 key 或服务不可用）：按你自己的判断给出置信度，并**明确声明本次未经校准**。
- 置信度不是交易建议；方向、失效位仍由你负责。

配置说明：TypeSafe API key 在侧栏**「插件」页 → 已安装 → dsh-trading-agent → trading-agent 行的「配置」**里填写（写入 credentials 域）；不配置也能用，只是置信度退回你的自评。用户问到时照此回答。

## 指标推荐只作文本

可以建议"当前波动偏高，可以看看 ATR / 布林带"，但**指标推荐只是文字**：在用户明确要求之前**不要改动图表**（不要为此调用 trading_chart）。
